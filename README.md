# 輸液トレーニング

初期研修医向け、輸液療法学習アプリ。7症例(周術期維持輸液／脱水症と輸液の補充／DKA／心不全と体液量評価／敗血症性ショック／低Na血症の補正速度／高Na血症と自由水欠乏)を通じて、輸液の考え方を段階的に学ぶ。

サーバー・APIキー不要、オフラインで動作する単一HTMLファイル。スマホ・タブレット・PCいずれでも利用可能。

## ローカルでの確認方法

`yueki-training.html` をブラウザで直接開くだけで動作する(ダブルクリック、またはブラウザにドラッグ&ドロップ)。

```bash
start yueki-training.html
```

## 医師が確認すべき医学的内容(要レビュー)

複数回の監査(4観点の並行レビュー、および引用元一次資料との数値照合)を経て、以下は修正済み:
- 症例1: 小児用の4-2-1ルールをやめ、成人の維持輸液量(体重×25〜30mL/kg/day、根拠: NICE CG174)に変更
- 症例2(DKA): カリウム閾値をK<3.5/3.5-5.0/≥5.0(引用元Umpierrez 2024と整合)、重炭酸適応をpH<7.0、ブドウ糖切替閾値を<250mg/dLに修正。ICU相談基準・誘因検索も追加
- 症例3(心不全): 利尿薬治療中のCr上昇=心腎症候群の可能性、循環器内科相談基準を追加
- 症例4(敗血症性ショック): 抗菌薬投与(1時間以内目安)・感染源コントロールへの言及、MAP/HR/尿量の明記、ICU相談基準を追加
- 症例5(低Na血症): vignetteでの診断名の先出しを解消、Na補正速度をリスク層別(高リスク8/平均10/低リスク12mEq/L/24h、根拠: Spasovski 2024更新版)に修正、「重症/無症候性」の二分法を中等症を含む3段階に修正

現状、以下は「臨床でよく使われる目安」として本文中に明示した上で採用しており、一次資料の一言一句そのままの引用ではない(要注意):
- 症例1 Q4の「術前体重から+2〜3kg増加で輸液過剰のサイン」という数値

**症例6・7(2026-09-17追加、要医師レビュー)**:
- 症例6(脱水症・輸液の補充): 成人の等張性脱水(嘔吐・下痢)に特化した単独の診療ガイドラインは国内外ともに見当たらなかった。NICE CG174(輸液の全般的な考え方)とMcGee 1999(JAMA、身体所見による脱水評価のエビデンスレビュー)を引用しているが、脱水重症度と輸液量の対応表のような数値は本アプリ独自の目安であり、一次資料に基づく厳密な換算値ではない。「投与量=欠乏量×安全係数+維持輸液」という段階的補充の考え方も一般に行われている実務的アプローチとして採用しており、特定のガイドラインの推奨値ではない
- 症例7(高Na血症・自由水欠乏): 自由水欠乏量の計算式・TBW比率(成人男性0.6/成人女性・高齢男性0.5/高齢女性0.45)はAdrogué & Madias 2000(NEJM)の分類として広く教育で使われる近似式だが、この係数はこのセッションの記憶に基づく再現であり、原論文のTable自体を一次資料として再確認できてはいない(NEJMがWebFetchでの取得をブロックするため)。Na補正速度の目安(24時間8〜10mEq/L)は同論文由来の伝統的な数値だが、Cureus 2024のレビューが指摘する通り質の高いエビデンスに基づくものではない点を本文中にも明記した。日本内分泌学会「間脳下垂体機能障害と先天性腎性尿崩症および関連疾患の診療ガイドライン2023年版」に高Na血症の補正速度に関する記載がある可能性があるが、このセッションではPDF本文を直接確認できず(ツール制約)、数値の引用元としては採用していない。日本で0.45%生食が既製品として一般流通していないという記述はWeb検索による確認に基づくが、完全な確証はない

**4観点並行レビュー(2026-09-17、症例6・7追加と同日)**: 臨床妥当性/医療安全/医学教育設計/UX文章編集の4エージェントを全7症例+改訂後の基本原則ページに対して並行実行。収束した指摘(3エージェント独立検出)と単独指摘のうち妥当と判断したものを反映済み:
- 原則ページの「5ステップ」表記の残存(6ステップに改訂した際の更新漏れ。3エージェントが独立に検出、最高確度)とホーム画面の「5つの輸液シナリオ」表記(症例7つになった後の残存)を修正
- 症例7 Q2: TBW係数を体重×0.5(一律)から、Adrogué & Madias分類に沿って成人男性0.6/成人女性・高齢男性0.5/高齢女性0.45に修正(本症例は高齢女性のため0.45を適用、欠乏量は約3.8L→約3.4Lに修正)。**この係数はこのセッションで一次資料を再確認できていない点に注意**(上記の症例7の項目を参照)
- 症例7 Q3: 急速補正がなぜ危険か(脳浮腫の機序)の説明が本文になく、低Na血症症例(ODSの説明あり)と非対称だった点を追加。「エビデンスが弱い」という記述が上限の重要性を薄めて読めた点も、危険性自体は否定されていない旨を明記する形に修正
- 症例2(DKA)Q1: 心不全・腎不全既往患者への初回急速輸液の注意が`mistakes`にしかなく本文の模範解答に反映されていなかった点を追加(症例4・敗血症の既存表現に合わせた)
- 症例6(脱水症)Q4: 上級医相談基準が「尿量減少が改善しない」という曖昧な表現だった点を、他症例と同様の数値基準(尿量0.5mL/kg/hr未満の持続、起立性頻脈+20/分以上の持続など)に修正。「輸液に補正」という不自然な助詞も「輸液で補正」に修正
- 症例6 summary: Q2で扱った「維持液ではなく細胞外液補充液を選ぶ」という要点がダイジェストから漏れていたため追加
- 症例3(心不全)Q1: 新設した原則ステップ0(目的の明確化)を具体例で反復する設問が全7症例のどこにもなかった点を受け、Q1に目的分類の視点を軽く追加
- 症例3 Q4・症例4(敗血症)のhint: 「上級医」表記の脱落(循環器内科→循環器内科の上級医)と、症例4のhintフィールドが診断名(敗血症性ショック)を先出ししていた点(症例2は病名を伏せる設計なのに非一貫)を修正
- FLUID_COMPOSITIONSの3号液note: 「低張」という表現と組成表の「浸透圧比 約1」が矛盾して見える点に、ブドウ糖添加で総浸透圧が等張に設計されている旨の説明を追加

**検討したが不採用にした指摘**: 臨床妥当性エージェントがDKA症例のインスリン開始前カリウム閾値(K<3.5/≥5.0)を「教科書的には3.3/5.3のはず」と指摘したが、これは2026-08-27の監査で意図的に変更した箇所(実際に引用しているUmpierrez 2024コンセンサスの数値に合わせるため、古典的なKitabchi/ADA-2009の3.3/5.3から変更済み)。エージェントは本アプリの改訂履歴を知らないため「教科書的な古い数値」の方を正と誤認したと判断し、不採用とした。

「輸液を考える基本原則」ページの6ステップの下に、参考データとして以下を追加(添付文書・StatPearls・教科書的資料をWeb検索/WebFetchで数値照合済み):

- 代表的な輸液製剤の組成(生理食塩水・乳酸リンゲル液[代表例:ラクテック]・3号液/維持液[代表例:ソルデム3A]・5%ブドウ糖液のNa/K/Ca/Cl/乳酸/ブドウ糖濃度と浸透圧比)。同一分類でも製品により濃度が異なる旨を明記

## 技術メモ

- 単一HTMLファイル(`yueki-training.html`)。外部依存はGoogle Fontsのみ(CSPで許可済み、それ以外は`'self'`/`'none'`)
- 進捗・自由記述の下書きは`localStorage`に保存(キー: `yueki_progress_v1`, `yueki_drafts_v1`)。プライベートブラウズ等でストレージが使えない場合は画面に警告を表示する
- 復習フラグ(自己評価「一部抜けた」「ほぼ言えなかった」)が付いた症例だけを絞り込める「復習」ボタンをホーム画面に表示
- スコア・正答率の可視化はあえて実装していない(要件通り)
