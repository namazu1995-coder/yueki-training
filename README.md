# 輸液トレーニング

初期研修医向け、輸液療法学習アプリ。5症例(周術期維持輸液／DKA／心不全と体液量評価／敗血症性ショック／低Na血症の補正速度)を通じて、輸液の考え方を段階的に学ぶ。

サーバー・APIキー不要、オフラインで動作する単一HTMLファイル。スマホ・タブレット・PCいずれでも利用可能。

## ローカルでの確認方法

`yueki-training.html` をブラウザで直接開くだけで動作する(ダブルクリック、またはブラウザにドラッグ&ドロップ)。

```bash
start yueki-training.html
```

## 医師が確認すべき医学的内容(要レビュー)

複数回の監査(4観点の並行レビュー、および引用元一次資料との数値照合)を経て、以下は修正済み:
- 症例1: 小児用の4-2-1ルールをやめ、成人の維持輸液量(体重×25〜30mL/kg/day、根拠: NICE CG174)に変更
- 症例2(DKA): カリウム閾値をK<3.5/3.5-5.0/≥5.0(引用元Umpierrez 2024と整合)、重炭酸適応をpH<7.0、ブドウ糖切替閾値を<250mg/dLに修正。ICU相談基準・誘因検索も追加
- 症例3(心不全): 利尿薬治療中のCr上昇=心腎症候群の可能性、循環器内科相談基準を追加
- 症例4(敗血症性ショック): 抗菌薬投与(1時間以内目安)・感染源コントロールへの言及、MAP/HR/尿量の明記、ICU相談基準を追加
- 症例5(低Na血症): vignetteでの診断名の先出しを解消、Na補正速度をリスク層別(高リスク8/平均10/低リスク12mEq/L/24h、根拠: Spasovski 2024更新版)に修正、「重症/無症候性」の二分法を中等症を含む3段階に修正

現状、以下は「臨床でよく使われる目安」として本文中に明示した上で採用しており、一次資料の一言一句そのままの引用ではない(要注意):
- 症例1 Q4の「術前体重から+2〜3kg増加で輸液過剰のサイン」という数値

参考文献は各症例末尾に著者/団体・タイトル・雑誌名・年・URLを明記(実在するガイドライン・論文をWeb検索/WebFetchで検証済み)。

「輸液を考える基本原則」ページの5ステップの下に、参考データとして以下を追加(添付文書・StatPearls・教科書的資料をWeb検索/WebFetchで数値照合済み):
- 体液の分画(体重比60-40-20ルール: 総体液量60%、細胞内液40%、細胞外液20%[間質液15%・血漿5%]、体重60kgでの具体例)
- 代表的な輸液製剤の組成(生理食塩水・乳酸リンゲル液[代表例:ラクテック]・3号液/維持液[代表例:ソルデム3A]・5%ブドウ糖液のNa/K/Ca/Cl/乳酸/ブドウ糖濃度と浸透圧比)。同一分類でも製品により濃度が異なる旨を明記

## 技術メモ

- 単一HTMLファイル(`yueki-training.html`)。外部依存はGoogle Fontsのみ(CSPで許可済み、それ以外は`'self'`/`'none'`)
- 進捗・自由記述の下書きは`localStorage`に保存(キー: `yueki_progress_v1`, `yueki_drafts_v1`)。プライベートブラウズ等でストレージが使えない場合は画面に警告を表示する
- 復習フラグ(自己評価「一部抜けた」「ほぼ言えなかった」)が付いた症例だけを絞り込める「復習」ボタンをホーム画面に表示
- スコア・正答率の可視化はあえて実装していない(要件通り)
