# 輸液トレーニング

初期研修医向け、輸液療法学習アプリ。5症例(周術期維持輸液／DKA／心不全と体液量評価／敗血症性ショック／低Na血症の補正速度)を通じて、輸液の考え方を段階的に学ぶ。

サーバー・APIキー不要、オフラインで動作する単一HTMLファイル。スマホ・タブレット・PCいずれでも利用可能。

## ローカルでの確認方法

`yueki-training.html` をブラウザで直接開くだけで動作する(ダブルクリック、またはブラウザにドラッグ&ドロップ)。

```bash
start yueki-training.html
```

## 医師が確認すべき医学的内容(要レビュー)

実装時点でドラフトから反映した3点の修正:
- 症例1: 小児用の4-2-1ルールをやめ、成人の維持輸液量(体重×25〜30mL/kg/day)に変更
- 症例4: 「バランス晶質液」という表記をやめ、「乳酸/酢酸リンゲル液(細胞外液補充液)」に統一
- 症例5: vignetteで「SIADHパターン」と診断名を言い切らず、体液量正常(euvolemic)の所見提示に留め、鑑別は設問側に配置

そのうえで、以下の数値・基準は要確認(施設プロトコルや最新ガイドラインとの整合性を医師の目でチェックしてほしい箇所):

1. **症例1**: 成人維持輸液量の係数 25〜30mL/kg/day(20〜35mL/kg/dayという幅の記載を含む)
2. **症例2(DKA)**: 初期輸液速度(最初の1時間15〜20mL/kg目安)、インスリン開始前のK閾値(<3.3／3.3-5.3／>5.3mEq/L)、インスリン投与速度(0.1単位/kg/hr)、血糖低下速度上限(50〜70mg/dL/hr)、ブドウ糖液切替の血糖閾値(200〜250mg/dL)、重炭酸投与の適応(pH<6.9)
3. **症例3(心不全)**: 数値基準は少ないが、体液量評価の記載内容が実診療の感覚と合っているか
4. **症例4(敗血症性ショック)**: 初期輸液量30mL/kg(J-SSCG2024/SSC準拠との記載)、乳酸クリアランス評価の運用が実際の記載と合っているか
5. **症例5(低Na血症)**: Na補正速度上限(24hで8mEq/L、ODS高リスク患者で6mEq/L程度、48hで18mEq/L)、3%高張食塩水の目標上昇幅(数時間で4〜6mEq/L)

## 技術メモ

- 単一HTMLファイル(`yueki-training.html`)。外部依存はGoogle Fontsのみ(CSPで許可済み、それ以外は`'self'`/`'none'`)
- 進捗・自由記述の下書きは`localStorage`に保存(キー: `yueki_progress_v1`, `yueki_drafts_v1`)。プライベートブラウズ等でストレージが使えない場合は画面に警告を表示する
- 復習フラグ(自己評価「一部抜けた」「ほぼ言えなかった」)が付いた症例だけを絞り込める「復習」ボタンをホーム画面に表示
- スコア・正答率の可視化はあえて実装していない(要件通り)
